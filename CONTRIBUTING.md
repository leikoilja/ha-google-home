# Contributing

Thanks for helping with the Google Home integration.

- **Questions:** ask in [GitHub Discussions](https://github.com/leikoilja/ha-google-home/discussions/categories/q-a).
- **Bugs and feature requests:** [open an issue](https://github.com/leikoilja/ha-google-home/issues/new/choose).
- **Translations, code and docs:** see [Contributing](https://ha-google-home.pages.dev/contributing/) in the documentation for how to set up, test and submit a change.
